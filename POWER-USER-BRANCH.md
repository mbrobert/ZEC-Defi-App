# power-user branch

Snapshot of the advanced build (2026-08-13), preserved before the Oilskin v1
simple pivot — modes (Simple/Full/Direct-LP), adjustable LTV to 50%, pool
picker with membership filter, per-position range/rebalance/auto-compound
controls, claim destinations, compound-now, EVM wallet binding, and the full
health-factor dashboard (`prototype/index.html`).

These features return in a later release, gated behind an "advanced" surface
on top of the v1 core. Development continues on `main` (see
`docs/V1-SIMPLE.md`).
